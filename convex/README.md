# Convex Scaffold (Phase 0)

This folder is a migration scaffold only. It does not replace Supabase yet.

## Included

1. `schema.ts`
2. `entitlements.ts` (read queries)
3. `projects.ts` (read queries)
4. `threads.ts` (read queries)

## Not Included Yet

1. Mutations/writes
2. Billing webhooks
3. Runtime event write path
4. Auth provider integration glue

## Goal

Define canonical read contracts first so web and desktop can migrate with parity and minimal drift.
