# Chat and Resources

## Goal

Use community conversation and durable knowledge together.

## Mental Model

Chat is live participation. Resources are durable shared knowledge. Both can help a community become more useful over time.

## Rules

1. Chat should feel live and member-centered.
2. Resources should be curated and durable.
3. Moderation should be role-gated.
4. Shared community knowledge should not be confused with private user memory.
5. Useful community signal should be intentionally converted into durable context.

## Related Concepts

- `community`
- `resource`
- `memory`
- `role`
