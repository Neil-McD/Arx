# Member Quickstart

## Goal

Join communities, use their resources and chat, and work with AI threads that can use community context.

## Core Steps

1. Sign in.
2. Join or open a community.
3. Use community chat and resources.
4. Open the workspace.
5. Start or continue a thread.
6. Select a community lens when the thread should use a community's context.
7. Ask the agent for help with a concrete task.

## Member Mental Model

Communities give you access to people, shared knowledge, and agent capability around a domain. The workspace is where you use that context to get work done.

## Rules

1. You can only use community context when you have access.
2. Switching a thread lens affects future turns, not prior turns.
3. Community resources are shared knowledge, not private memory.
4. Paid or gated communities may require approval, purchase, or membership.
