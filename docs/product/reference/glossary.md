# Glossary

## Accepted Community Memory

Community-owned intelligence admitted through the evidence, compiler, and
community-cognition boundary.

## Agent

An AI product surface. Polynet distinguishes the member's personal agent from
the community-owned agent.

## Builder

A person or organization creating a community intelligence system on Polynet.

## Builder Authority

Community authority available to an eligible owner/admin for builder-only
operations such as staged resource changes.

## Community

The gated product, repository, and authority boundary around members, agents,
resources, access, and shared intelligence.

## Community Context

Explicit server-validated community context used for a subsequent agent turn.
It does not grant access or change agent identity.

## Entitlement

Backend access truth for a product, community, capability, or plan.

## MCP

Model Context Protocol. Polynet provides one official OAuth-protected MCP
server for external harnesses and does not consume third-party MCP servers.

## Member Authority

Community authority for normal participation and authorized reads. Community-
owned agents always use this lane.

## Resource

Community-owned durable knowledge artifact.

## Role

Community relationship such as owner, admin, moderator, or member. Effective
authority is derived from role plus current permissions and entitlement.

## Skill

Reusable instruction package that shapes agent behavior without granting tool
authority.

## Internal Thread

An implementation primitive used for durable messages, context evidence, and
auditability. It is not standalone product navigation.

## Workspace Compatibility

Protected coding-harness state or legacy external wire vocabulary. It is not
the deleted standalone Workspace product.
