# Glossary

## Accepted Community Memory

Community-owned intelligence admitted through the evidence, compiler, and
community-cognition boundary, always with a source citation.

## Agent Page

The community's page (Agent tab on mobile) where a member has a private
conversation with the community agent.

## Builder

A person or organization creating a community intelligence system on Polynet.
In a community, builders are its owner and admins.

## Builder Authority

Community authority available to an eligible owner/admin for builder-only
operations such as staging resource changes.

## Community

The gated product, repository, and authority boundary around members, the
community agent, resources, access, and shared intelligence.

## Community Agent

The one AI agent each community has. It belongs to the community, acts for
each member inside that member's permissions, and replies to @mentions with
member authority.

## Community Context

Explicit server-validated community context used for a subsequent agent turn.
It does not grant access or change agent identity.

## Community Site

A community's own website on `polynet.page`, built by its founder with
`@polynet/cli` or the MCP. Staging only for now.

## Entitlement

Backend access truth for a product, community, capability, or plan.

## Join Page

A community's public entry page at `/c/<slug>` for joining, approval, sign-in,
and checkout. Formerly called the community funnel.

## MCP

Model Context Protocol. Polynet provides one official OAuth-protected MCP
server for builders' external AI harnesses and does not consume third-party
MCP servers.

## Member Authority

Community authority for normal participation and authorized reads. The
community agent always uses this lane when it acts on its own.

## Polynet Studio

Polynet's own web app at polynet.ai, where founders manage communities,
billing, and direct messages, and where members use communities today.

## Resource

Community-owned durable knowledge artifact.

## Role

Community relationship such as owner, admin, moderator, or member. Effective
authority is derived from role plus current permissions and entitlement.

## Internal Thread

An implementation primitive used for durable messages, context evidence, and
auditability. It is not standalone product navigation.

## Workspace Compatibility

Protected coding-harness state or legacy external wire vocabulary. It is not a
product surface.
