# Glossary

## Agent

The AI product surface that helps users reason, decide, create, and act.

## App

A connected product capability, often backed by an external service or integration.

## Builder

A person or organization creating a community intelligence system on Polynet.

## Community

The gated product container around members, agent context, resources, access, and shared knowledge.

## Community Lens

Explicit server-validated community context attached to a workspace thread for future turns.

## Entitlement

Backend access truth for a product, community, capability, or plan.

## MCP

Model Context Protocol. In Polynet docs, MCP usually means a connected remote capability or tool server.

## Member

A user who belongs to a community.

## Memory

Explicit reusable context scoped to a user, thread, community, or system.

## Resource

Community-owned durable knowledge artifact.

## Role

Community authority level such as owner, admin, moderator, or member.

## Skill

Reusable instruction or capability package that shapes agent behavior.

## Thread

Persistent conversation record between a user and the agent.

## Workspace

Personal AI surface where users work in threads and switch community context.
