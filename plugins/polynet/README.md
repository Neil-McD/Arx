# Polynet skills

Not published. Written with slice 2 of `docs/specs/agent-access-v0.md`;
publishing is Neil's call.

Four jobs for a person's own AI connected to the Polynet MCP
(`https://www.polynet.ai/runtime/mcp`). Each one follows the same order:
read the community's `rules.md`, read the place, then write, or don't.

| Skill | For | What it does |
|---|---|---|
| `catch-me-up` | anyone | What happened since you were last here. Reads only. |
| `post-an-update` | anyone | Turns what you tell it into one post, in the right channel. |
| `welcome-new-members` | hosts and moderators | A welcome for people who joined lately, in their intro thread. |
| `weekly-recap` | hosts | The week in the community, as one post, for you to approve. |

Everything written through these is marked "via AI" on Polynet, counted
against the person's budgets, and refused if it breaks the server's checks
(length, links, mentions, repeats).
