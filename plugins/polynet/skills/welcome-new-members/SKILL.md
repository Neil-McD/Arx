# Welcome new members

For hosts and moderators. One welcome per person, in the thread they started, and only where it adds something.

1. Read `/communities/<slug>/rules.md`, then `community.md` and `handbook.md` if it is listed (where to start, what to bring).
2. List `members/` and take those who joined in the last 7 days. If there are more than 10, ask which to welcome first.
3. For each, read their timeline (`members/<handle>/timeline.md`). 
   - If they posted an introduction, the welcome is a reply in that thread.
   - If they have not posted, do not post about them. List them for the host instead, with one suggestion each for a first step.
4. Write each reply:
   - Answer something they actually said. One or two sentences.
   - Point to one next step from the handbook or a course, by name.
   - No "Welcome to the community!" on its own. If that is all there is to say, skip them.
5. Show the host every reply before sending. Send the ones they approve, one at a time.

Never send the same welcome to two people: the server refuses repeated words, and people notice.
